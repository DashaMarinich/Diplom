План тестирования приложения «Мобильный хоспис».
Тип: мобильное приложение (Android).
Целевая аудитория: пациенты, родственники, волонтёры, сотрудники хосписа.
Назначение: предоставление актуальной информации о деятельности хосписа в удобном мобильном формате.
Основной функционал:
-Работа с новостями: просмотр, фильтрация по дате и категории, сортировка, добавление, редактирование, удаление (для авторизованных пользователей с правами редактора).
-Просмотр тематических цитат: скроллинг списка, разворачивание цитаты для полного отображения.
- Авторизация и выход из личного кабинета.
Структура приложения:
Экран авторизации Поля «login» и «password», кнопка «sign in», сообщения об ошибках валидации
Главный экран News, галочка развернуть список, показать все новости all news, обновить refresh, кнопка сортировки, фильтр: по категории, по дате, 
Карточка новости тема, дата, автор,  карандаш: добавить, удалить , редактировать, развернуть новость
Раздел «Тематические цитаты» список цитат сокращенно, скролл вверх/вниз, развернуть цитату для полного отображения. 
Профиль Выход Log out 
Данные для авторизации: login2; password2.
Границы тестирования:
Функциональное тестирование: 
- авторизация с валидными и не валидными данными, выход из личного кабинета,
- фильтр новостей по дате, по категории, сортировка, добавление новостей, редактирование новостей, удаление новостей
- раздел тематические цитаты, скроллинг вверх/вниз списка цитат, развернуть цитату.
UI/UX-тестирование:
- Читаемость текста, размеры шрифтов, контрастность
- Расположение кнопок, интуитивно понятная навигация.
Инструменты для тестирования: 
Среда разработки: AndroidStudio, 
Девайс: эмулятор Pixel 7 Pro, 
ПО: Android 13.0, API 33, 
Автоматизация тестирования: Фреймворк Espresso, отчет по результатам тестирования Allure

Сроки тестирования: 
- ручное тестирование: подготовка чек листа, тест кейсов, тестирование. 8 часов 
- автоматизация тестов: подготовка окружения в AndroidStudio, выбор тестов для автоматизации, написание и прогон тестов, подготовка отчетности. 8 часов
